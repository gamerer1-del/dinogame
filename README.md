# Lab Exodus（仮）

停電した研究所の地下から、逃げ出した恐竜を避けて地上へ脱出する、三人称のステルスホラーゲームです。
エンジンは Godot 4 で、PC（Windows / Mac）向けに作っています。

いまは **エリア1（B5 飼育ケージ区画）の、箱だけで作ったプロトタイプ** です。
見た目は後で Blender（Blender MCP）で作ったモデルに差し替える予定です。

## 遊び方

1. [Godot 4.3 以降](https://godotengine.org/download) をダウンロードします（.NET 版ではない普通の版で大丈夫です）。
2. このリポジトリをダウンロードします（GitHub の緑の「Code」→「Download ZIP」で展開）。
3. Godot を起動し、「インポート」から `project.godot` を選んで開きます。
4. 右上の ▶（F5）で遊べます。

## 操作

| 操作 | キーボード＋マウス | ゲームパッド |
| --- | --- | --- |
| 移動 | WASD | 左スティック |
| 視点 | マウス | 右スティック |
| しゃがむ（足音が小さい） | Ctrl / C | B |
| 走る（足音が大きい） | Shift | 左スティック押し込み |
| 調べる・拾う・隠れる | E | A |
| 空き缶を投げる | 左クリック | RT |
| 懐中電灯 | F | Y |
| マウスを解放 | Esc | Start |
| クリア後に最初から | R | Back |

## このプロトタイプでできること

- **観察室 → 飼育通路 → 給餌室 → 出口** の4区画。給餌室でカードキーを拾い、北の扉を開けて出口に入ればクリア。
- **ストーカー（小型の肉食恐竜）が2匹。** 通路・ケージ・観察室・給餌室を見回り、物音を聞けばどの部屋にも入ってくる。耳が良く、目は近く（約7m、しゃがむと約4m）しか見えない。
  - 状態は「巡回 → 警戒 → 捜索 → 追跡 → 捕獲」。見失うと捜索してから巡回に戻る。目の色が状態で変わる（黄→橙→赤）。
- **足音:** 歩く 6m、走る 14m、しゃがむ 2m まで聞こえる。水たまりの上では2倍。画面左上のメーターで確認できる。
- **空き缶:** 投げると落ちた場所で 12m 届く音が鳴り、恐竜がそちらを調べに行く。
- **隠れ場所:** ロッカーと冷蔵庫。中にいる間は見つからないが、出入りの音（3m）は聞かれる。
- **扉を開ける音（10m）で恐竜が寄ってくる。**
- **チェックポイント:** 通路の入口と給餌室の入口。捕まるとそこからやり直し。

## 数値の調整

遊んでみて難しすぎる・簡単すぎるときは、ファイル先頭の定数を変えてください。

- `scripts/player.gd`: 移動速度、足音の距離（`NOISE_*`）、水たまりの倍率
- `scripts/stalker.gd`: 速度、見える距離と角度、捜索する時間、見失うまでの時間
- `scripts/level.gd`: 明るさ（`AMBIENT_ENERGY`、`LIGHT_BOOST`、`LIGHT_RANGE_ADD`）、恐竜の見回りルート（`_spawn_stalkers`）

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `scenes/main.tscn` | 起動シーン（中身は `level.gd` がコードで組み立てる） |
| `scripts/level.gd` | 部屋・照明・恐竜・アイテムの配置、ナビメッシュの生成 |
| `scripts/game.gd` | オートロード `Game`。入力設定、物音の通知、チェックポイント、捕まった／クリア |
| `scripts/player.gd` | 主人公（三人称カメラ、移動、足音、隠れる、投げる、懐中電灯） |
| `scripts/stalker.gd` | 恐竜のAI（5状態のステートマシン、聴覚と視覚、経路探索） |
| `scripts/hud.gd` | 画面表示（足音メーター、気配、ヒント、フェード） |
| `scripts/throwable.gd` ほか | 空き缶、隠れ場所、カードキー、扉、明滅する非常灯 |

## 自動テスト

画面なしで起動して、ナビメッシュの生成と恐竜の反応（巡回・物音で警戒・捜索・見つけて追跡）を確認できます。

```
godot --headless --path . -- --selftest
```

最後に `SELFTEST RESULT: PASS` と出れば成功です（画面なし実行ではメッシュ関連のエラーが多数出ますが、無害です）。
