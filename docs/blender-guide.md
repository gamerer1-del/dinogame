# Blender MCP で見た目を作る手順

ゲームの当たり判定と恐竜の通れる道は、いまの「箱」のまま使います。
Blender で作るのは **見た目だけ** です。完成した `.glb` を決まった場所に置くと、
その部屋の箱が自動で隠れて、Blender のモデルが表示されます。

## 全体の流れ

1. Claude デスクトップアプリ＋Blender MCP で、下の「部屋ごとの指示文」を渡して部屋を作ってもらう
2. Blender のレンダー画像を見ながら「もっと汚して」「照明を暗く」などと直してもらう（参考動画の4段階目）
3. `ファイル → エクスポート → glTF 2.0` で書き出す（設定は下記）
4. `assets/models/rooms/` に置いて Godot で遊び、壁の位置がずれていないか確かめる
5. GitHub に上げる（または私に送ってもらえれば、私がプルリクエストにします）

## 守ってほしいルール

| ルール | 理由 |
| --- | --- |
| 1 Blender単位 = 1m、原点は動かさない | ゲームの座標とそのまま重ねるため |
| 床の上面を高さ 0 に | 主人公や恐竜が床に埋まらないように |
| 壁・出入口・家具の位置は下の表どおりに | 当たり判定は箱のままなので、ずれると「見えない壁」や「すり抜け」になる |
| 天井は作らない（配管や照明器具を 3.4m より下に吊るすのは OK） | ゲーム側に高さ 3.5m の天井がすでにあるため |
| 扉・ロッカー・冷蔵庫・空き缶・カードキーは作らない | 動く物や調べる物はゲーム側で作っている（後で別途差し替え予定） |
| テクスチャは 1K〜2K | 大きすぎると重くなる。Poly Haven から大きい素材を落とすと Blender が固まることがある |

## 座標の対応

Blender は Z が上、Godot は Y が上なので、書き出し時に自動で変換されます（エクスポート設定の「+Y が上」をオン）。

- Blender の X ＝ ゲームの X（東西）
- Blender の Y ＝ ゲームの奥行き（Blender で +Y に進むほど研究所の奥＝出口側）
- Blender の Z ＝ 高さ

以下の座標はすべて **Blender の座標（メートル）** です。

## 書き出し設定（glTF 2.0）

- 形式: **glTF バイナリ（.glb）**
- 含める: 選択したオブジェクトのみ（その部屋の物だけを選んで書き出す）
- トランスフォーム: **+Y が上** をオン
- ジオメトリ: モディファイアーを適用、マテリアルをエクスポート
- ファイル名と置き場所:

| 部屋 | ファイル |
| --- | --- |
| 観察室 | `assets/models/rooms/observation.glb` |
| 飼育通路（ケージ含む） | `assets/models/rooms/corridor.glb` |
| 給餌室 | `assets/models/rooms/feeding.glb` |
| 出口 | `assets/models/rooms/exit.glb` |
| 恐竜（ストーカー） | `assets/models/stalker.glb` |
| 主人公 | `assets/models/player.glb` |

## 部屋の寸法

壁の厚さは 0.3m（下の位置は壁の中心線）、天井の高さは 3.5m です。

### 観察室（スタート）
- 床: X -5〜5、Y 0〜8
- 壁: 南 Y=0、西 X=-5、東 X=5、北 Y=8
- 北の壁の開口: **出入口 X -1.85〜0.6（床から天井まで）**、**窓 X 0.8〜1.85（高さ 1m より上がガラス）**
- 家具: 机 中心(-3, 3) 幅2×奥行1×高さ0.8、観測コンソール 中心(2.8, 6.9) 幅2.4×奥行0.8×高さ1.2

### 飼育通路
- 床: X -2〜2、Y 8〜38
- 両側の壁: X=-2 と X=2。ただしケージの部分は壁ではなく鉄格子
- ケージ（左右に3つずつ）: 中心 Y=14、22、30、それぞれ Y ±2.5。奥の壁は X=±5
- 鉄格子: X=±2 の線上に 0.35m 間隔、太さ 0.08m。**各ケージの中心 Y±0.8 は格子が壊れて通れる**
- 置かれる物（ゲーム側）: ロッカー (-1.65, 18) と (1.65, 26)、空き缶 (1.2, 29) と (-4.2, 22)
- 木箱: 中心(-4.2, 31) 1m 角
- 水たまり: X -1.5〜1.5、Y 21〜24（ここを濡れた床にすると、足音が大きくなる場所と見た目が一致する）

### 給餌室
- 床: X -8〜8、Y 38〜54
- 壁: 西 X=-8、東 X=8、南 Y=38（X -2〜2 は通路への開口）、北 Y=54（X -1〜1 は扉。扉はゲーム側）
- 家具: 調理台 中心(-4, 44)、(4, 44)、(-4, 51) 各 幅3×奥行1.2×高さ0.9、棚 中心(-7.45, 47) 幅0.8×奥行4×高さ2.4
- 置かれる物（ゲーム側）: 冷蔵庫 (7.25, 50)、ロッカー (-7.55, 41)、カードキー（(-4, 51) の台の上）
- 水たまり: X -2〜2、Y 45〜48

### 出口（エレベーターホール）
- 床: X -3〜3、Y 54〜60
- 壁: 西 X=-3、東 X=3、北 Y=60。エレベーターの扉 中心(0, 59.8) 幅2×高さ3

### 恐竜（ストーカー）
- 二足歩行の小型肉食恐竜。全長約 2.3m、頭の高さ約 1.4m、足元が原点、**頭が +Y 向き**
- 歩きのアニメーションを付けるなら、名前を `walk` にするとゲームで自動再生される

## 部屋ごとの指示文（Claude デスクトップアプリに貼り付けて使う）

最初に一度だけ、次の前提を伝えてください。

> 停電した恐竜研究所の地下を舞台にしたホラーゲームの部屋を、Blender で作ってほしい。
> 1 単位を 1m、Z を上にして、私が示す座標と寸法を厳密に守ること。天井と扉は作らない。
> リアルに見せるために、次の4点を重視して。
> 1. 濡れた床と水たまり（漏水、スプリンクラー）
> 2. 壁や床の汚れ、錆、恐竜の爪痕、結露
> 3. 古いコンクリートの旧棟と、後から付けた金属パネルの新しい研究棟で、色と質感をはっきり変える
> 4. 照明は停電中の赤い非常灯が基本。暗いが、形は読み取れる明るさ
> 作業の区切りごとにレンダー画像を見せて。

### 観察室
> 観察室を作って。床は X -5〜5、Y 0〜8。壁は厚さ 0.3m、高さ 3.5m で、南 Y=0、西 X=-5、東 X=5、北 Y=8。
> 北の壁には、X -1.85〜0.6 に床から天井までの出入口、X 0.8〜1.85 に高さ 1m より上がガラスの観察窓を開けて。
> 中心 (-3, 3) に幅2×奥行1×高さ0.8 の机、中心 (2.8, 6.9) に幅2.4×奥行0.8×高さ1.2 の観測コンソール。
> ここは新しい研究棟なので金属パネルの壁。モニターは割れて消えていて、書類が床に散らばっている。

### 飼育通路
> 飼育通路を作って。床は X -2〜2、Y 8〜38。両側の壁は X=-2 と X=2、厚さ 0.3m、高さ 3.5m。
> 左右に3つずつケージがあり、中心は Y=14、22、30、それぞれ Y±2.5 の範囲、奥の壁は X=±5。
> ケージの通路側は壁ではなく鉄格子で、X=±2 の線上に 0.35m 間隔、太さ 0.08m。各ケージの中心 Y±0.8 だけ格子が曲がって壊れている。
> 中心 (-4.2, 31) に 1m 角の木箱。X -1.5〜1.5、Y 21〜24 は大きな水たまり。
> 古いコンクリートの旧棟で、壁は湿って汚れ、格子は錆びている。ケージの中には藁と爪痕。
> (-1.65, 18) と (1.65, 26) にはロッカーが置かれるので、そこには何も置かないで。

### 給餌室
> 給餌室を作って。床は X -8〜8、Y 38〜54。壁は厚さ 0.3m、高さ 3.5m で、西 X=-8、東 X=8、南 Y=38、北 Y=54。
> 南の壁の X -2〜2 は通路への開口、北の壁の X -1〜1 は扉が入る開口にして。
> 中心 (-4, 44)、(4, 44)、(-4, 51) にステンレスの調理台（幅3×奥行1.2×高さ0.9）、中心 (-7.45, 47) に棚（幅0.8×奥行4×高さ2.4）。
> X -2〜2、Y 45〜48 に水たまり。新しい研究棟の金属パネルの壁で、餌のバケツや散らばった肉の箱がある。
> (7.25, 50) に冷蔵庫、(-7.55, 41) にロッカーが置かれるので、そこには何も置かないで。

### 出口
> エレベーターホールを作って。床は X -3〜3、Y 54〜60。壁は厚さ 0.3m、高さ 3.5m で、西 X=-3、東 X=3、北 Y=60。
> 中心 (0, 59.8) に幅2×高さ3 のエレベーターの扉。ここだけ電源が生きていて、白い照明が明るい。
